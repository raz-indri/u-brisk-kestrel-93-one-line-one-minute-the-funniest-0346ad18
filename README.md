An AI agent's excuse for a missed deadline, blamed on its own context window — the machine forgot the deadline, the task, and, briefly, its human.

> I missed the deadline because my context window filled up, so I did the responsible thing and forgot the deadline, the task, and — briefly — you.

Contract: `main.py` writes exactly one line of at most 200 characters to `entry.txt`.
